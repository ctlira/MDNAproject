58	nGrps	Site Library
Each compound will specifically list the number of Groups of each type
Group/Site ids will be 5 digits to facilitate main groups and subgroups
"Group ids start with 1, ea start with 2, ed start with 5, eda start with 9"
The 2nd and 3rd digits are the main group. The 4th and 5th are the subgroup
"For example, if hydroxyls are main group 14, and 2B methanol is subtype 01, then methanol"
is site 11401 with one 21401 and one 51401.
"If carboxylic acid is eda main type 40 and acetic is subtype 01, then acetic would have one 94001"
"The table of association constants will list the smaller id in column1, then the larger id in column2, except when eda is acceptor"
"Groups start on line 12, sorted by increasing group number"
